## ✨ Features

- **Dynamic Hero Section:** Custom cartoon avatar with interactive motion, client social proof badges, and animated typography.
- **Custom Fonts & Aesthetics:** Tailored modern aesthetic featuring custom `MicrophoneCheck` font and sleek dark glassmorphism effects.
- **Client Proof & Infinite Marquee:** Seamless logo carousel highlighting brands and 99+ satisfied clients with 5-star ratings.
- **Selected Works Showcase:** Grid showcase of commercial packaging designs, beverage labels, pouches, and branding systems.
- **Services & Capabilities:** Detailed cards covering Packaging Design, Brand Identity, 3D Visualization, and Production Artwork with interactive software stack.
- **Interactive FAQ Accordion:** Clean, animated accordion addressing common client questions regarding turnaround time, deliverables, and commercial print preparation.
- **Infinite Testimonials Carousel:** Verified client recommendations and reviews.
- **Bottom Glass Call-To-Action Dock:** Persistent floating action dock with direct WhatsApp consultation booking and social links.
- **Contact & Booking Modal:** Direct messaging and appointment booking popup modal.

## 🚀 Running Locally

### 1. Prerequisites
- Node.js (v18+ recommended)
- npm (v9+ recommended)

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/farabiahadtafim/portfolio.git
cd portfolio
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser at:
```
http://localhost:5173
```

### 4. Build for Production
```bash
npm run build
```
